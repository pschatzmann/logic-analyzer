Uses the portable, bit-banged Capture class - there is currently no hardware-timed capture backend for AVR.

On the Uno/Nano, GPIO0 and GPIO1 are the hardware Serial RX/TX pins that are used to communicate with PulseView, so those two channels show the serial traffic and can't be used for measuring. Pass a different start pin to begin() if you need all 8 channels (e.g. start pin 2 for GPIO2-9).

Note: PinReader::readAll() reads the PINB/PIND input registers (the actual physical pin state), not PORTB/PORTD (the output latch), which only reflects the real voltage for pins configured as INPUT.

On the Arduino Mega 2560 the GPIO numbers map to different port registers than on the Uno/Nano, so a separate PinReader is used: the default start pin is 22 (pins 22-29 = PINA). Start pins A0-A7 (PINF) and A8-A15 (PINK) are also read directly from the port register; any other start pin falls back to the (slower) digitalRead().

The default serial speed is 9600 baud (SERIAL_SPEED): make sure you select the same baud rate in PulseView, otherwise the device will not be detected.
