Default serial speed: 921600 baud (SERIAL_SPEED). Both examples work with the Arduino-Pico core for RP2040 and RP2350 boards (e.g. Pico, Pico W, Pico 2, Pico 2 W).

Config file: config_pico.h

Software Loop Capture (<tt>Capture</tt>)

The logic-analyzer-pico example uses the portable, bit-banged Capture class - simple, but limited in top sampling rate like on any other board using it.

Hardware-Timed Capture via PIO + DMA (<tt>PicoCapturePIO</tt>)

The logic-analyzer-pico-pio example (PicoCapturePIO, in src/capture_raspberry_pico.h) drives the RP2040/RP2350's PIO block with DMA, capturing samples with no CPU involvement per sample and reaching much higher sustained rates than the software loop. No trigger support yet.
