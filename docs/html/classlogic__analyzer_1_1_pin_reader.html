Detailed Description

Arduino Mega specific implementation Logic for the PinReader. The Mega GPIO numbers are not mapped to PORTB/PORTD like on the Uno/Nano: we read the port register that contains the start pin. Supported start pins with a fast register read: 22-29 (PINA), A0-A7 (PINF) and A8-A15 (PINK). For any other start pin we fall back to digitalRead().
