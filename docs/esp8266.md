# ESP8266

| Processor | Max Freq | Max Samples | Pins | GPIO      |
|-----------|----------|-------------|------|-----------|
| ESP8266   |  1038680 |       50000 |   4  | GPIO12-15 |

Config file: [config_esp8266.h](https://github.com/pschatzmann/logic-analyzer/blob/main/src/config_esp8266.h)

Uses the portable, bit-banged `Capture` class - there is currently no
hardware-timed capture backend for this chip.
