## Logic Analyzer Pico PIO

This is a sketch which is implementing an Arduino based Logic Analyser using the PIO and DMA of the Raspberry Pico (RP2040/RP2350) for hardware-timed capturing.

It has been tested with the [Arduino-Pico core](https://github.com/earlephilhower/arduino-pico). Triggers are not supported yet.

See [docs/pico.md](../../docs/pico.md) for details.
